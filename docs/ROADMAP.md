# BingeTrail roadmap

## Phase 0 — Foundation (current)

- Flutter targets for Android, iOS, and web
- Product shell, theme, tests, CI, and initial database schema

## Phase 1 — Real catalog (complete)

- [x] TMDB client behind a data boundary
- [x] Search, trending, movie details, and TV details
- [x] Poster loading, error handling, and loading states
- [x] Locally persistent watchlist

## Phase 2 — Accounts and tracking

- Supabase project and authentication
- Supabase watchlist sync and viewing statuses
- Season and episode progress
- Offline queue and synchronization

## Phase 3 — Retention

- Upcoming-release calendar
- Push notifications
- Ratings, notes, statistics, and data export
- Turkish and English localization

## Phase 4 — Beta and stores

- Accessibility and device testing
- Privacy policy, terms, and account deletion
- TestFlight and Google Play closed testing
- Store listing assets and staged release

## Later

- Friends, collaborative lists, and spoiler-safe comments
- Importers for common tracking exports
- Sustainable optional subscription features
